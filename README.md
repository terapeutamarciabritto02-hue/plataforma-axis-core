# AXIS CORE™
### Plataforma Terapêutica Multidimensional · v1.0.0

## Stack
- Frontend: Next.js 15 + TypeScript + Tailwind
- Backend: FastAPI + Python 3.12
- Banco: Supabase PostgreSQL + RLS
- Mobile: Expo SDK 52 + React Native
- IA: Claude (Anthropic)
- Pagamentos: Stripe
- Email: Resend
- MQTT: EMQX

## Módulos
- 4 painéis web (Admin, Terapeuta, Cliente, Aluno)
- App mobile iOS + Android
- Engine AXIS™ (8 mesas)
- PPG Biometria via webcam/câmera
- IA Supervisora integrada
- PDF com assinatura digital
- Email transacional
- Push notifications
- Stripe billing (3 planos)
